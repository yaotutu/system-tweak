# system-tweak

这是一个“记录本机变更、提炼配置经验”的仓库。

它不自动同步电脑状态，不自动执行配置，也不维护“哪些变更已经应用”的台账。所有真实修改均由用户自己完成；仓库只保存事实记录和从事实中提炼出的可复用信息。

## 当前工作流

1. 真实修改完成后，自动写入 `logs/YYYY-MM.md`。
2. 如果这次修改命中 `configurations/INDEX.md` 中的关注范围，再询问是否提取到 `configurations/`。
3. 提取结果只保存摘要、关键片段和经验结论，不保存整份系统配置，也不视为其他机器的目标状态。

## 目录约定

```text
logs/             当前电脑的真实变更日志；本机私有，不同步
configurations/   从日志提取出的配置记录；可由用户手动同步
configurations/INDEX.md  修改触发索引
knowledge/        历史遗留目录；不属于当前工作流
backups/          历史遗留目录；不属于当前工作流，也不同步
```

`configurations/` 不是自动同步或自动恢复目标。它只是一份“从事实中提炼出来的经验摘要”。

## 使用方式

### 记录真实修改

真实修改完成后，不需要询问，直接写入当月日志。日志只记录已经发生的事实，不补造时间、命令或结果。

### 提取配置

如果修改命中了索引里的项目，可以在征得同意后，把日志中可复用的内容整理成 `configurations/<软件或功能>/<主题>.md`。

提取时要：

- 注明来源日志；
- 只保留关键片段、选择结果和注意事项；
- 不保存整份真实配置；
- 不假设其他电脑拥有相同硬件、版本或行为。

## Git

`logs/` 和 `backups/` 永不同步。`configurations/`、仓库说明和规则文档可以由用户自行选择是否同步。
