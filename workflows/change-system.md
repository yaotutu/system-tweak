# change-system：修改本机配置

## 边界

本工作流用于修改当前这台电脑的系统配置。

会修改：

- 当前电脑的真实系统配置；
- 软件包、服务、自启动项或环境变量；
- 本机 `logs/YYYY-MM.md`。

不会修改：

- `targets/`；
- `workflows/`；
- 其他电脑。

Git：

- 一般不修改仓库文档；
- 不需要 commit/push。

## 流程

1. 明确用户要改变的行为，并检查当前系统状态。
2. 修改持久配置前创建带时间戳的备份。
3. 执行实际变更：
   - 安装/卸载软件包；
   - 修改配置；
   - 启用/禁用/重启服务；
   - 修改自启动或环境。
4. 按目标行为验证。
5. 验证完成后立即写入本机日志。
6. 若用户可能希望其他电脑也拥有该行为，询问是否进入 `workflows/update-targets.md`。

## 日志要求

- 一项完整系统任务记一条日志，不按每个文件或主题拆分。
- 已产生实际变更但任务中断时，立即写 `⚠️ 部分完成`。
- 未产生实际变更时不要写日志。
- 日志必须包含修改路径、包名、关键命令、备份位置和验证结果。

## 完成报告

向用户说明：

- 已修改什么；
- 备份在哪里；
- 如何验证；
- 是否建议写入目标库；
- 如果不建议，说明原因。
